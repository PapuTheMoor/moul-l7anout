# Workshop implementation loop

Read shared context and claim file ownership. Freeze the contract. Write failing tests for domain behavior, implement the smallest correct change, then run the relevant tests. Target 80% coverage of implemented domain code. Run lint, typecheck, and build before integration. Inspect UI at mobile and desktop widths. Review code before final handoff. Record exact verification outcomes in the task board; never claim unrun checks passed.

Optional features are cut first. Prioritize confirmation, deterministic arithmetic, undo, clearly labeled sample inputs, and a rehearsed demo.
